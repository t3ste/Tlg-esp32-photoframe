Weather Icon Color Reference

Every weather-condition icon, in both selectable icon sets, shown monochrome (the default) and in its assigned traffic-light severity color (opt-in "Colored icons" setting, Settings → Overlays). Generated by scripts/generate_weather_icon_colors_doc.py from the exact same bitmaps and color table the firmware uses - never hand-edited pixel data, so this always reflects what the device actually draws.

How to use this page: review whether each color assignment still makes sense, then edit the weather_icon_color_for_id() table in main/image_processor.c (and the mirrored COLORS_BY_ICON_ID list at the top of the generator script, so this page stays in sync) if something should change. Colors are shown at the exact hex values the e-paper firmware uses (palette[] in image_processor.c) - not a web-safe approximation - so what you see here is what the hardware actually renders on a color-capable panel. Grayscale-only panels always fall back to plain black, regardless of this setting.

Color legend

Green - good / light, no particular concern
Yellow - moderate / caution
Red - severe / hazardous
Blue - snow (distinct from the rain scale)
Black - neutral, no warning implied
