Weather Icon Color Reference

Every weather-condition icon, in both selectable icon sets, shown on both a white and a black background - both monochrome (the default) and in its assigned traffic-light severity color (opt-in "Colored icons" setting, Settings → Overlays). Generated by scripts/generate_weather_icon_colors_doc.py from the exact same bitmaps and color table the firmware uses - never hand-edited pixel data, so this always reflects what the device actually draws.

Why both backgrounds matter (not just a nice-to-have): the firmware draws this icon in two places whose background can be either black or white - the photo overlay bar (black by default, white if "Invert overlay colors" is on) and Agenda mode's day-divider chip (flips polarity to match the chosen page background). A color that looks fine on one background and disappears on the other is a real bug, not a style choice. This is exactly how the "neutral" categories (partly cloudy/overcast/snow grains) were caught going invisible - a literal black icon on a black Agenda background - and fixed to use whatever the surrounding text color already is (already contrast-safe for its own background) instead of a fixed black. That's why the neutral column shows an adaptive black-on-white / white-on-black pair rather than a single fixed-color swatch.
How to use this page: review whether each color assignment still makes sense on both backgrounds, then edit the weather_icon_color_for_id() table in main/image_processor.c (and the mirrored COLORS_BY_ICON_ID list at the top of the generator script, so this page stays in sync) if something should change. Colors are shown at the exact hex values the e-paper firmware uses (palette[] in image_processor.c) - not a web-safe approximation - so what you see here is what the hardware actually renders on a color-capable panel. Grayscale-only panels always fall back to plain black/white, regardless of this setting.

Color legend

Green - good / light, no particular concern
Yellow - moderate / caution
Red - severe / hazardous
Blue - snow (distinct from the rain scale)
Neutral - no fixed color; adapts to whatever already contrasts with its background

Each icon cell shows two side-by-side pairs: the default monochrome glyph (top) and the same glyph in colored-icon mode (bottom) - each pair itself shown on white (left) and black (right) background, so any background-dependent contrast problem is visible directly rather than needing to imagine it. Icon size is 24×24px on the actual device (Font24 text-height match) - upscaled 4× here for legibility, so the edge pixelation shown is exactly what the real, small on-device icon looks like blown up, not an artifact of this page.
